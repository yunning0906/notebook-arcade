# 手繪毛毛蟲貪吃蛇（Doodle Snake）

溫暖療癒的方格筆記本手繪風格貪吃蛇網頁遊戲。擺脫傳統像素或街機霓虹感，營造如在手帳紙上漫步的童趣體驗。

## ✨ 特色與風格契合點
- **方格紙手帳美學**：米白底色（`#F7F3E9`）、淡棕方格網紋與手繪色鉛筆邊框、和紙膠帶點綴。
- **粉彩可愛毛毛蟲**：由柔和糖果粉彩圓點（Pastel Circles）組成，身體爬行時帶有彈性伸縮蠕動（Squish & Stretch）效果，大眼睛隨移動方向注視並會隨機眨眼，兩側有微小可愛小短腿與微晃雙觸角。
- **手繪甜美果實**：枝葉相連的雙櫻桃（Cherries）、飽滿草莓（Strawberry）與罕見金色幸運星果，被吃掉時迸發彩色鉛筆碎屑與漂浮得分文字。
- **專屬 Web Audio 音效**：
  - **轉彎音**：彈性的小小水滴噗嚕音（Bubbly Water Drop / Bloop）。
  - **吃果子**：晶瑩剔透的清脆鈴鐺與水晶琴音（Crystal Bell Chime）。
  - **背景音樂**：舒緩慢活的八音盒旋律（Music Box Lullaby）。
- **漫步步調切換**：
  - 散步 ☕（悠閒慢速 230ms/格）
  - 漫遊 🍃（標準步調 170ms/格）
  - 踏青 🏃（暢快速度 125ms/格）
- **紙張邊界規則**：
  - 自由漫遊 🌀（無限穿越，無拘無束）
  - 筆記邊界 📐（紅筆邊線，經典碰壁結束）
- **全方位操作支援**：
  - 鍵盤：方向鍵（↑ ↓ ← →）或 WASD、空白鍵暫停、R 重新開始。
  - 行動裝置：支援螢幕滑動手勢（Swipe）與手繪粉彩圓形虛擬方向鍵（D-Pad）。

## 📂 專案檔案結構
- `index.html` - 遊戲主頁面與手帳佈局
- `style.css` - 手繪風格樣式表與觸控響應
- `js/audio.js` - Web Audio API 音效合成引擎
- `js/caterpillar.js` - 粉彩毛毛蟲繪圖、插值動態與表情系統
- `js/food.js` - 手繪櫻桃、草莓與幸運星果實系統
- `js/particles.js` - 彩色鉛筆彩屑與漂浮文字特效
- `js/game.js` - 遊戲核心循環、輸入緩衝與狀態控制
