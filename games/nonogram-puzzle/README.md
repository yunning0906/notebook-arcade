# NONOGRAM - 手繪鉛筆數織手帳 (Notebook Picross)

依據「在數學筆記本上拿色鉛筆塗鴉」的溫暖懷舊情懷打造，延續西瓜遊戲、2048 與一筆畫系列的手繪文具美學。

## ✨ 核心特色 (Key Features)

- 📝 **方格筆記本紙張美學 (Notebook Graph Paper)**:
  - 米黃底色（`#F7F3E9`）搭配精緻坐標方格線。
  - 手繪鉛筆邊框（`#524338`）與 5×5 粗線分組，視覺清晰。
- ✏️ **真實鉛筆手感與音效 (Realistic Pencil Soundscape)**:
  - 塗黑格子時有細膩逼真的**鉛筆沙沙聲**（Web Audio API 濾波合成）。
  - 空白標記（✖）時有清脆俐落的筆尖輕敲聲。
  - 橡皮擦復原與通關慶祝音效。
  - 76 BPM 療癒八音盒背景音樂（可隨時靜音）。
- 🌸 **粉彩綻放終局特效 (Pastel Blossom Transformation)**:
  - 依據行列提示數字推理並塗滿正確格子後，黑白石墨素描將無縫轉化為**柔和粉彩色插圖**（櫻花粉、蜜桃橘、薄荷綠、天藍）。
  - 落下手帳專屬完成戳印，帶來滿滿成就感。
- 📖 **手繪手帳畫廊 (Sketchbook Gallery)**:
  - 收錄 5×5（入門）、10×10（溫馨手繪）、15×15（細緻挑戰）共 18 幅原創謎題。
  - 解鎖的所有插圖將永久保存於個人手帳畫廊中。

## 🕹️ 操作方式

- **滑鼠左鍵 / ✏️ 鉛筆工具**：點擊或按住拖曳，為格子塗上鉛筆排線陰影。
- **滑鼠右鍵 / ✖️ 叉叉工具**：標記確定為空白的格子。
- **鍵盤快捷鍵**：
  - `1` 或 `P`：切換鉛筆
  - `2` 或 `X`：切換標記叉叉
  - `Ctrl + Z` / `Cmd + Z`：復原上一步
- **手機 / 平板**：支援單指直接滑動塗色、工具列一鍵切換模式。

## 🚀 本地執行

使用任何靜態伺服器皆可直接執行：

```bash
npx serve .
# 或
python3 -m http.server 8000
```
瀏覽器開啟 `http://localhost:3000` 或 `http://localhost:8000` 即可遊玩！
