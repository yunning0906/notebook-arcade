# 2048 (Suika Game Aesthetic Edition) 🍉🔢

A minimalist, warm, and charming 2048 puzzle game handcrafted with the exact visual and audio aesthetic of **Suika Game**:
- 🎨 **Aesthetic**: Rice paper notebook grid background (`#F7F3E9`), hand-drawn pencil borders, borderless colored-pencil pastel tiles, and cute tiny black dot eyes with playful idle blinking animations.
- 🎵 **Sound & Music**: Continuous uninterrupted slow healing music box BGM (80 BPM, Web Audio API), water droplet slide bloops, crisp glockenspiel/xylophone merge bells, and fairy combo arpeggios.
- 🎮 **Controls**: Multi-input support (Arrow Keys / WASD, Mobile Touch Swipe, and Desktop Mouse Drag / Flick).
- 🧩 **Difficulty Modes**: 3×3 Challenge, 4×4 Classic, and 5×5 Relax with independent best scores saved to `localStorage`.
- ⚡ **Zero Dependencies**: Pure HTML5, Vanilla CSS, and JavaScript.

## 🚀 One-Click Deployment

### Option 1: Deploy to Vercel
1. Push this repository to GitHub.
2. Visit [vercel.com](https://vercel.com) and click **Add New Project**.
3. Select your repository. Because this is a static project, no build command is needed!
4. Click **Deploy**, and your game is live globally in seconds!

### Option 2: Deploy to GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Source**, select `Deploy from a branch` -> `main` -> `/ (root)`.
4. Click **Save**. Your site will be published at `https://<username>.github.io/<repo-name>/`.

## 🕹️ Local Development

To run locally using Python:
```bash
python3 -m http.server 8080
```
Then open `http://localhost:8080` in your browser.
