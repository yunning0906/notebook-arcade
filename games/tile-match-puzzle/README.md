# PAPER TILES - 手繪卡牌三消手帳 (Tile Match 3)

精緻溫暖的手繪紙質風格卡牌三消 / 靜態麻將連連看遊戲，與西瓜遊戲、Picross 數織手帳、水彩分類一脈相承。

## 遊戲特色

1. **手繪疊層與自然投影**：
   - 暖調網格手帳紙底底台，卡牌具有自然紙張投影。
   - 處於底層被壓住的卡牌會呈現真實的紙片陰影與灰階鎖定態，頂層可拾取的卡片則呈現高光飽滿、浮動懸停微光。
2. **清脆啪聲翻牌音效**：
   - Web Audio API 擬真合成翻牌紙牌「啪」聲、滑入托盤風聲、三消清脆鈴聲與舒緩手帳 BGM。
3. **秩序感 7 格托盤**：
   - 點擊卡片自桌面流暢飛入底部 7 格收納槽，並自動與相同圖案緊鄰排列。
   - 湊齊 3 張立即觸發手繪紙花碎屑迸散，卡牌整齊向左回縮排列，極具收納整理的解壓舒暢感。
4. **文具主題 3 大輔助道具**：
   - ↩️ **回溯時光 (Undo)**：退回托盤最後一張卡牌。
   - 🔀 **重新整理 (Shuffle)**：桌面現有剩餘卡牌重新洗牌。
   - 📌 **書籤暫存 (Extract)**：將托盤中的卡牌移至上方臨時書籤槽。
5. **保證可解的關卡**：
   - 第 1 關：晨光餐桌 (18 張牌)
   - 第 2 關：午後咖啡館 (36 張牌)
   - 第 3 關：秘密植物園 (54 張牌)
   - 第 4 關：手帳工作台 (72 張牌)
   - 第 5 關：野餐手帳大師 (90 張牌)
   - 無盡隨機挑戰模式
