# 水彩試管倒水 · Watercolor Sort Puzzle

> 手繪方格紙張風格 · 慢節奏療癒調色益智遊戲

## 遊戲特色
- **手繪實驗桌與細線試管**：鉛筆細線勾勒玻璃唇口、刻度線與木質試管架，搭配暖米白方格紙底紋。
- **莫蘭迪水彩分層**：精選抹茶綠、芋泥紫、奶杏粉、冰川藍、薑黃金、豆沙紅等 8 款柔和水彩，具備表面張力半月液面（Meniscus）與水彩暈染質感。
- **擬真「咕嚕咕嚕」水流氣泡音效**：透過 Web Audio API 純代碼即時合成水流與上升氣泡音，細膩逼真。
- **慢節奏音樂盒 BGM**：68 BPM 治癒系卡林巴／音樂盒旋律，無倒數計時與壓力。
- **豐富輔助功能**：無限步數復原 (Undo)、重置 (Restart)、增加備用試管 (+1 Tube) 與最佳解提示 (Hint)。
- **36 幅手繪關卡**：內建 BFS 求解驗證演算法，保證 100% 可解。
